進階設定

地點建議

一般使用者不需要 API 金鑰。網站已設定 Google Places 時會優先使用；未設定或暫時失敗就自動改用 OpenStreetMap。優先顯示約 220 公尺內、較可能實際消費的餐飲／零售／生活服務。

一般使用者不需要 API 金鑰。若站長已設定 Google Cloud Vision，會優先使用文件 OCR；否則自動使用免費的本機 Tesseract。兩者都會先進確認頁。

每月到指定日期後，App 會在下一次開啟時補入一筆一般支出；若設定 29–31 日而該月較短，會記在當月最後一天。已產生的舊帳不會因修改規則而回頭改寫。

🧾 最快：直接填發票實付金額（免設規則）
